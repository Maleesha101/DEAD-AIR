# Public Challenge Artifacts

Only reviewed, player-visible challenge assets belong in this directory.

Before adding an artifact:
- Confirm it contains synthetic data only.
- Verify that it does not expose organizer answers, final flags, signing keys, private configuration, or unrelated data.
- Record its purpose and SHA-256 in the campaign manifest.
- Confirm that it can be generated or verified reproducibly.
- Include a dependency reference to the stage that consumes it.

Large or reproducible binaries should be generated by documented scripts when practical rather than committed without explanation.
